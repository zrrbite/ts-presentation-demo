# GitHub Setup Instructions

## Option 1: Create via GitHub Web Interface

1. Go to https://github.com/new
2. Repository name: `presentation-demo`
3. Description: `Live demo of Claude Code TypeScript workflow - from zero to production-ready in 10 minutes`
4. Public repository
5. **DO NOT** initialize with README (we already have one)
6. Click "Create repository"

Then run these commands:

```bash
cd ~/dev/presentation-demo
git remote add origin https://github.com/YOUR_USERNAME/presentation-demo.git
git branch -M main
git push -u origin main
```

## Option 2: Install GitHub CLI (Recommended)

```bash
sudo pacman -S github-cli
gh auth login
cd ~/dev/presentation-demo
gh repo create presentation-demo --public --source=. --description="Live demo of Claude Code TypeScript workflow" --push
```

## After Pushing

Your repo will be live at:
`https://github.com/YOUR_USERNAME/presentation-demo`

You can then:
- Share the link in your presentation
- Let others clone and try the workflow
- Use it as a live demo during the talk
